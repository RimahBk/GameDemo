# Norse Mythology Deck Builder

React, TypeScript, and Vite starter configured with Tailwind CSS and the libraries
listed in the project setup guide.

## Run locally

Node.js 24 LTS is included in `.tools` for this machine. In PowerShell, from the
project folder:

```powershell
.\.tools\node-v24.19.0-win-x64\npm.cmd run dev
```

Open <http://localhost:3000>. To build or check the project, run:

```powershell
.\.tools\node-v24.19.0-win-x64\npm.cmd run build
.\.tools\node-v24.19.0-win-x64\npm.cmd run type-check
.\.tools\node-v24.19.0-win-x64\npm.cmd run lint
```

The `.tools` runtime is local to this project and excluded from Git. On another
machine, install Node.js 24 LTS and use the regular `npm` commands instead.
